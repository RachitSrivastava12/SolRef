# SolRef

**Explore the infrastructure behind Solana.**

[Website](https://www.solref.fun)

SolRef is an independent reference hub for developers who want to understand how Solana works under the hood.

The goal is simple: make Solana's infrastructure easier to explore, understand, and learn through curated resources, technical explanations, and links to relevant documentation and implementations.

## What you'll find

- **Solana Architecture** — Explore the components and systems that power the network.
- **Runtime & Execution** — Learn about the SVM, sBPF, Sealevel, transactions, and program execution.
- **Validator Infrastructure** — Discover validator clients, consensus, networking, and block production.
- **Storage & Data** — Explore AccountsDB, snapshots, indexing, and state management.
- **RPC & Infrastructure** — Find RPC providers, APIs, developer tools, and infrastructure resources.
- **Research & Learning** — Discover technical articles, documentation, specifications, and useful repositories.
